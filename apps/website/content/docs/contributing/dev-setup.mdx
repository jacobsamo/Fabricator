---
title: Running from Source
description: Set up a local development environment to run Fabricator from source.
---

Use this for contributing to the main Fabricator app, not for running the docs site.

## Backend setup

```bash
git clone https://github.com/philderks/Fabricator.git
cd Fabricator
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Run the Flask app:

```bash
python3 run.py
```

Development defaults bind to `127.0.0.1:5000` and store data in the platform app-data directory. Use `.env.example` as a starting point for local overrides.

## Frontend setup

```bash
cd apps/frontend
npm install
npm run dev
```

The frontend is Vue 3 + Vite. Production releases serve the built frontend through Flask, but local development can run Vite separately.

## Build frontend

```bash
cd apps/frontend
npm run build
```

The build output goes to `apps/frontend/dist` and is served by the backend in production-like mode.

## Website and docs setup

The marketing site and documentation live in `apps/website`. Docs content is stored in `apps/website/content/docs`.

```bash
cd apps/website
bun install
bun run dev
```

Useful website checks:

```bash
bun run types:check
bun run lint
bun run build
```

The website publishes `install.sh`, `update.sh`, and `uninstall.sh` from the repository `tools/` directory. `bun run dev`, `bun run build`, and `bun run start` automatically run `bun run sync:scripts`, which copies those scripts into `apps/website/public/` so they are available as `/install.sh`, `/update.sh`, and `/uninstall.sh`.

## Tests

Run backend tests from the repository root:

```bash
pytest
```

The test suite covers app factory behavior, storage, routes, installers, Java compatibility, Modrinth integration, backup/restore behavior, player management, and runtime status contracts.

## Useful source locations

| Path | Purpose |
| --- | --- |
| `apps/backend/core/app.py` | Flask app factory and blueprint registration. |
| `apps/backend/core/config.py` | Environment-driven config object. |
| `apps/backend/server/routes.py` | Main server, files, mods, Java, metrics, loader, console routes. |
| `apps/backend/server/installer/` | Loader-specific server installers. |
| `apps/backend/modrinth/` | Modrinth API client and routes. |
| `apps/backend/backups/` | Backup configs, storage, scheduler, progress, restore. |
| `apps/backend/server/players/` | Player files, live commands, and player routes. |
| `apps/frontend/src/router/index.js` | Dashboard route map. |
| `apps/frontend/src/stores/` | Pinia state stores. |
| `apps/cli/` | Fabricator CLI package and CLI tests. |
| `apps/website/src/routes/` | Marketing/docs route files. |
| `apps/website/content/docs/` | Canonical documentation content. |
| `tools/install.sh` | Release installer. |
| `tools/update.sh` | Native update wrapper copied to the website public root. |
| `tools/uninstall.sh` | Native uninstall helper copied to the website public root. |
